The problem

Every AI session starts with 12k wasted tokens.

Your agent re-reads the same files, asks the same questions, and rebuilds the same context. Every time you open a new session.

Without Sprint Agent

Re-explore, re-explain, repeat

  • ~12,300 tokens of re-exploration per session
  • No memory of what you did yesterday
  • Agent forgets every blocker and decision
With Sprint Agent

Pick up exactly where you left off

  • ~2,100 tokens · 83% reduction
  • Persistent sprint memory in .sprint/
  • Agent knows what shipped, what's next, what's blocked
In action

Two minutes from install to first sprint.

Drops a .sprint/ folder in your repo with current sprint, backlog, and an AGENT.md your AI agent auto-reads.

~/my-saas — sprint-agent
How it works

Markdown over databases. Git-native. Zero deps.

No background server, no SQLite, no Docker. Just files your agent reads and your editor opens.

01

init

Creates .sprint/ with backlog, current sprint, and the right config file for your agent (CLAUDE.md / .cursorrules / AGENTS.md / …).

02

Daily 30-min

One ticket per session. Your agent reads the sprint, picks the next TODO, works, updates the file.

03

Friday retro

One command generates the retrospective template. Score, document blockers, plan the next sprint.

04

git sync

Sprint history is version-controlled. Your .sprint/ diffs show progress over time.
